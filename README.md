# SBI · Sổ hàng

Trang dẫn cố định: https://sohangsbi.github.io/

Trang này đọc `link.json` từ repo để chuyển tới địa chỉ Tunnel đang dùng. Máy chủ công ty tự cập nhật file khi khởi động web.

Repo chỉ chứa trang dẫn và địa chỉ truy cập công khai. Không đưa database, mật khẩu hoặc token vào repo.

Bật Pages tại Settings → Pages → Deploy from a branch → main → /(root).
